# 온습도 + 빛 통합 테스트

`test/environment_test.py`는 DHT11의 온습도와 KY-018의 상대 밝기를 2초마다 출력하고 if문으로 환경을 판단합니다. 실패한 측정은 미측정으로 표시하며 이전 값을 새 측정처럼 사용하지 않습니다.

## KY-018에는 ADC가 필요합니다

KY-018의 S는 아날로그 출력입니다. Raspberry Pi 4에는 아날로그 입력이 없으므로 **MCP3008 같은 ADC가 추가로 필요합니다.** GPIO에 S를 직접 연결해도 빛의 세기를 읽을 수 없습니다. 이 예제는 MCP3008의 CH0를 사용합니다. ADC가 없는 상태에서는 DHT11만 실행할 수 있습니다.

### 배선

모든 배선은 전원을 끈 상태에서 진행합니다. 모듈의 실제 + / - / S 표시를 확인하세요.

| 센서 | Pi 연결 |
| --- | --- |
| DHT11 + | 물리 1번, 3.3V |
| DHT11 - | 물리 6번, GND |
| DHT11 S | 물리 7번, BCM GPIO4 |
| KY-018 + | 물리 17번, 3.3V |
| KY-018 - | 물리 9번, GND |
| KY-018 S | MCP3008 CH0 (칩 1번 핀) |

MCP3008 DIP-16 기준이며 브레이크아웃 보드는 핀 이름을 따릅니다.

| MCP3008 | Pi 연결 |
| --- | --- |
| VDD (16), VREF (15) | 3.3V |
| AGND (14), DGND (9) | GND |
| CLK (13) | 물리 23번, BCM11 |
| DOUT (12) | 물리 21번, BCM9 |
| DIN (11) | 물리 19번, BCM10 |
| CS (10) | 물리 24번, BCM8 |

전원과 GND는 브레드보드 레일로 공유할 수 있습니다. KY-018과 ADC 모두 3.3V로 공급합니다. 이 예제는 RPi.GPIO 소프트웨어 SPI를 사용하므로 SPI 커널 인터페이스를 활성화할 필요가 없습니다. 다른 SPI 드라이버나 프로그램이 같은 핀을 제어하지 않도록 하세요. DHT11 단독 테스트도 동시에 실행하지 마세요. 기존 모터 핀 GPIO18/13과는 겹치지 않습니다.

## 실행

```sh
cd /home/ubuntu/on-jan
# ADC가 없다면 온습도만 실측 (빛은 미연결로 표시)
sudo ./venv/bin/python test/environment_test.py

# MCP3008 연결 후 원시 ADC 값 확인
sudo ./venv/bin/python test/environment_test.py --light mcp3008
```

센서를 가린 상태의 ADC 값과 밝은 곳에서의 ADC 값을 각각 기록하세요. 아래 900, 150은 설명용 예시이며 실제 측정값으로 교체합니다. 제품 회로에 따라 밝아질수록 ADC 값이 낮아질 수도 높아질 수도 있고, 두 방향 모두 지원합니다.

```sh
sudo ./venv/bin/python test/environment_test.py --light mcp3008 --dark-raw 900 --bright-raw 150
# 5회 측정 후 종료, JSON 출력
sudo ./venv/bin/python test/environment_test.py --light mcp3008 --dark-raw 900 --bright-raw 150 --count 5 --json
```

밝기(%)는 보정한 두 지점 사이의 상대값을 0~100으로 제한한 값이며, lux나 선형적인 실제 조도를 의미하지 않습니다. MCP3008에는 센서 연결 자동 확인 기능이 없어 미연결이나 잘못된 배선도 숫자로 보일 수 있습니다. 센서를 가리고 비췄을 때 ADC 값이 변하는지 먼저 확인하세요.

## 임시 판단 기준

| 항목 | if 조건 | 결과 |
| --- | --- | --- |
| 습도 | 70% 이상 | 습하다 |
| 습도 | 70% 미만 | 습도 보통 |
| 온도 | 28°C 이상 | 덥다 |
| 온도 | 24°C 이상, 28°C 미만 | 따뜻하다 |
| 온도 | 18°C 미만 | 춥다 |
| 온도 | 나머지 | 쾌적하다 |
| 상대 밝기 | 70% 이상 | 밝다 |
| 상대 밝기 | 30% 미만 | 어둡다 |
| 상대 밝기 | 나머지 | 은은하다 |

예: `습하다 / 따뜻하다 / 어둡다`. 보정되지 않은 빛 값과 실패한 온습도 값은 해당 항목 판단에서 제외합니다. Ctrl+C로 종료합니다.
