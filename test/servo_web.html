작은 움직임을 조율하다.

두 개의 서보 모터를 한 자리에서. 신호를 조절하고, 움직임을 반복해보세요.

01 · 움직임 설정

0–180° 명목 각도 · 90° = 7.5% Duty (1.5ms). 실제 각도는 모터별로 다를 수 있어요.

50 Hz 기준 · 5% = 1ms / 7.5% = 1.5ms / 10% = 2ms

1회 = 시작 → 끝 → 시작. 회전 수가 아닌 왕복 횟수예요.

초기화는 실제 원점 감지가 아니라 중앙 명령을 보내는 동작입니다. 현재 테스트가 끝난 뒤 사용할 수 있어요.

기존 핀 유지 · GPIO18 / GPIO13 · 50Hz PWM
MG996R은 각도 제어형 서보입니다. 외부 5–6V 전원과 공통 GND를 사용하세요. MG996R은 실제 위치를 Pi로 돌려주지 않습니다. 아래 숫자는 마지막 명령이며 도달을 확인한 각도가 아닙니다. 종료 시 PWM이 해제되어 손이나 부하에 의해 위치가 바뀔 수 있습니다. 정확한 각도 확인에는 외부 센서와 보정이 필요합니다. 브라우저를 닫아도 설정한 유한 횟수까지 실행됩니다.
