# 전체 로테이션 테스트

`python -m onjan_total --confirm-external-power`로 실행하고 메인 화면의 **전체 로테이션 테스트**를 사용한다. 기존 시간 기반 서보 시험과 별개인, 실제 로드셀 피드백을 쓰는 수동 시작 작업이다.

1. `/weight`에서 빈 플랫폼으로 영점 조정, 실제 무게추로 g 보정. 같은 잔을 계속 쓴다.
2. 빈 잔을 올려 **빈 잔 무게 저장**. 컵에 원하는 양만 채운 뒤 **채운 잔 무게 저장**. 목표는 넘치기 전 여유가 있는 총무게로 잡는다. 두 기준은 `data/pour-refs.json`에 저장되며 빈 기준을 다시 잡으면 이전 목표를 폐기한다. 영점·보정 또는 장착을 바꾸면 두 기준도 다시 측정한다.
3. 잔을 비우고 같은 위치에 놓는다. 시작 시 현재 무게가 빈 기준 ±2g 이내인지 검사한다. 첫 시험은 병을 비우고 기구가 180°부터 0°까지 충돌하지 않는지 확인한다. 물을 쓸 때는 전자부와 분리하고 받침 트레이를 둔다.
4. 시작 명령 180°/180° → 4초에 걸쳐 100°/50°. 각 단계에서 CH1(2번)을 40, 30, 20, 10, 0°로, 이후 CH0(1번)를 90, 80, …, 0°로 낮춘다. 추가 10° 이동은 약 0.7초. 무게가 계속 증가하는 동안은 더 기울이지 않는다.

## 관성과 신호 판단

- 입력은 기존 5회 RAW 이상치 제거 평균에서 환산한 g. 같은 타임스탬프의 값을 여러 번 읽어도 새 표본으로 세지 않는다.
- 기준 저장과 시작 전: 2초 이상에 걸친 최근 7개 표본에서 최대–최소 ≤2g, 앞·뒤 3개 중앙값 차이 ≤0.6g. 8초 내 안정되지 않으면 시작하지 않는다. 값은 실측 검증 전 시험용이다.
- 이동 중과 이동 직후 1초는 **유입 추정**에서 제외한다. 이후 새 표본 5개를 보고, 끝 3개가 모두 시작보다 3g 이상 무겁고 뒤쪽 두 표본 중앙값이 앞쪽보다 1g 이상 증가하면 유입 추정. 이때는 같은 각도에서 다시 관찰한다. 반동/불안정, 컵 제거 또는 무게 손실, 2초 이상 오래된 값, 통신 오류에는 더 기울이지 않는다.
- 목표선은 정착 중에도 감시한다. 최신 무게가 목표 이상이면 즉시 추가 기울임을 중단하고 두 채널을 1.5초에 걸쳐 180°로 복귀한다. 0.4초 후 PWM OFF. 다시 안정된 무게가 목표−2g 이상이면 완료, 아니면 순간 피크로 기록하고 자동 재시도하지 않는다. 상한을 넘긴 무게도 표시하므로 실제 넘침 여부는 별도로 확인한다.
- GUI 중단은 현재 작업 큐를 기다리지 않고 복귀를 요청한다. 90초·최저 각도 한계에서도 종료하며, 서버 종료 시 복귀보다 PWM 해제를 우선한다. 소프트웨어 중단은 물리적 비상정지가 아니다.

## 한계 및 검증

무게 하나로 **천천히 증가하는 센서 드리프트와 실제 액체 유입을 완벽히 분리할 수 없다**. 필터 지연, 낙하 중 액체, 복귀 시간 때문에 목표 초과도 가능하다. 자동 영점 추적은 실제 유입까지 지울 수 있어 사용하지 않는다. 물 없이 같은 동작을 반복해 무게가 유입 기준을 넘는다면 실액 시험 전에 기구 간섭·선 장력·전원 및 EMI를 해결한다. 실제 빈 잔/채운 잔에서 얻은 흔들림 범위로 허용값을 조정한다. 테스트: `python -m unittest discover -s tests -p test_pour.py`.
