# 전체 로테이션 테스트

`python -m onjan_total --confirm-external-power`로 실행하고 메인 화면의 **전체 로테이션 테스트**를 사용한다. 기존 시간 기반 서보 시험과 별개인, 실제 로드셀 피드백을 쓰는 수동 시작 작업이다.

1. `/weight`에서 빈 플랫폼으로 영점 조정, 실제 무게추로 g 보정. 같은 잔을 계속 쓴다.
2. 빈 잔을 올리고 **전체 로테이션 테스트**를 누른다. 컵이 비었는지는 사용자가 확인한다. 모터는 초음파(유효 거리 2~11cm, 1초 이내 최신값)가 연속 감지되는 동안 무게 안정화가 끝나야 움직인다. 감지가 끊기면 안정화 표본을 비운다. 주입 중 잔 미감지/거리 오류이면 즉시 추가 기울임을 멈추고 복귀한다. 안정화 실패 시 자동 시작하지 않는다.
3. 이번 빈 잔의 안정된 중앙값을 주입량 0g으로 고정한다. 저장된 빈 잔/채운 잔 파일은 쓰지 않는다. `/weight`의 플랫폼 영점과 counts/g는 그대로 유지된다. UI의 주입량은 이 기준 대비 증가량이다.
4. 시작 명령 180°/180° → 3초에 걸쳐 100°/80°. 각 단계에서 CH1(2번)을 75, 70, …, 0°로, 이후 CH0(1번)를 95, 90, …, 0°로 낮춘다. 추가 5° 이동은 약 0.16초. 무게가 계속 증가하는 동안은 더 기울이지 않는다.

## 관성과 신호 판단

- 입력은 기존 5회 RAW 이상치 제거 평균에서 환산한 g. 같은 타임스탬프의 값을 여러 번 읽어도 새 표본으로 세지 않는다.
- 시작 전: 2초 이상에 걸친 최근 7개 표본에서 최대–최소 ≤2g, 앞·뒤 3개 중앙값 차이 ≤0.6g. 8초 내 안정되지 않으면 시작하지 않는다. 값은 실측 검증 전 시험용이다.
- 유입 전 5° 탐색 이동에서는 0.25초 뒤 새 표본 2개가 모두 빈 잔 기준 ±1g이고 서로 0.3g 이내면 다음 각도로 진행한다. 그 밖에는 표본 5개로 확인한다. 최초 이동 및 유입 확인 후에는 이동 중과 이동 직후 1초를 **유입 추정**에서 제외한다. 이후 새 표본 5개를 보고, 끝 3개가 모두 시작보다 3g 이상 무겁고 뒤쪽 두 표본 중앙값이 앞쪽보다 1g 이상 증가하면 유입 추정. 이때는 같은 각도에서 다시 관찰한다. 반동/불안정, 컵 제거 또는 무게 손실, 2초 이상 오래된 값, 통신 오류에는 더 기울이지 않는다.
- 목표선은 정착 중에도 감시한다. 최신 무게가 시작 중앙값보다 22g 이상 증가하면 즉시 추가 기울임을 중단하고 두 채널을 1.5초에 걸쳐 180°로 복귀한다. 18g 이상에서 최근 세 표본이 연속 증가하고 1.5초 뒤 22g에 도달할 것으로 추정되면 먼저 복귀한다. 복귀 후 0.4초 대기하고 PWM OFF. 다시 안정된 순증가량이 22 ±5g 이내면 완료, 그 미만이면 미달, 초과하면 과충전으로 표시하고 자동 재시도하지 않는다. ±5g은 안정된 무게의 비교 허용치이며 주입 중단선이나 안정화 기준이 아니다.
- GUI 중단은 현재 작업 큐를 기다리지 않고 복귀를 요청한다. 90초·최저 각도 한계에서도 종료하며, 서버 종료 시 복귀보다 PWM 해제를 우선한다. 소프트웨어 중단은 물리적 비상정지가 아니다.

## 한계 및 검증

무게 하나로 **천천히 증가하는 센서 드리프트와 실제 액체 유입을 완벽히 분리할 수 없다**. 필터 지연, 낙하 중 액체, 복귀 시간 때문에 목표 초과도 가능하다. 자동 영점 추적은 실제 유입까지 지울 수 있어 사용하지 않는다. 물 없이 같은 동작을 반복해 무게가 유입 기준을 넘는다면 실액 시험 전에 기구 간섭·선 장력·전원 및 EMI를 해결한다. 실제 빈 잔/채운 잔에서 얻은 흔들림 범위로 허용값을 조정한다. 테스트: `python -m unittest discover -s tests -p test_pour.py`.
